# Directivas e Regras Globais do Projeto

## Regra Principal
- **NÃO** altere nenhuma funcionalidade, layout, lógica ou fluxo que não tenha sido explicitamente solicitado.

## Sugestões e Melhorias
- Qualquer melhoria, otimização ou correção **NÃO solicitada** deve ser apenas sugerida no chat, nunca aplicada ao código.

## Esclarecimento
- Se algo não estiver claro, pergunte antes de executar qualquer alteração.

## Formato Obrigatório de Resposta
Toda resposta com alterações de código deve obrigatoriamente conter:
1. **O que será alterado**
2. **O que NÃO será alterado**
3. **Confirmação de que nenhuma outra parte foi modificada**

## Alerta de Violação
- Se o usuário solicitar algo que viole estas diretrizes, aponte a inconformidade antes de prosseguir.
